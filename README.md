# README — База данных «Учёт заказов ателье индивидуального пошива»

## О проекте
Курсовая работа по дисциплине «Теоретические основы баз данных». Спроектирована и реализована реляционная база данных для предметной области «Учёт заказов ателье индивидуального пошива».

## Цель
Реализовать функционирующую реляционную БД для ателье и выполнить 9 запросов к ней.

## Задачи
- Анализ предметной области (клиент, портной, администратор, заказы, изделия, ткани, фурнитура)
- Построение ER-диаграммы (нотация Чена) и схемы БД
- Проектирование 11 таблиц с обоснованием типов атрибутов
- Развёртывание схемы в PostgreSQL
- Генерация тестовых данных (C++ + libpq)
- Выполнение 9 SQL-запросов с реляционными формулами и планами выполнения
- Визуализация результатов (Python + matplotlib)

## Стек
- **СУБД:** PostgreSQL 15
- **Генератор данных:** C++ (libpq)
- **Визуализация:** Python (matplotlib)
- **Среда:** macOS (Apple Silicon)

  ## Схема БД (11 таблиц)

`atelier`, `client`, `atelier_client`, `administrator`, `tailor`, `order`, `garment`, `fabric`, `fabric_garment`, `accessories`, `accessories_garment`

Используются ENUM-типы: `order_status`, `garment_type`, `cut_style_type`, `applicability_type`. Внешние ключи с `ON DELETE CASCADE`, составные первичные ключи для таблиц-связок.

## Быстрый старт

```bash
# 1. Создать БД
createdb atelier
psql -d atelier -f sql/create_schema.sql

# 2. Собрать и запустить генератор
g++ -std=c++17 src/generator.cpp -o generator -lpq
./generator

# 3. Выполнить запросы
psql -d atelier -f sql/queries.sql

# 4. Построить графики
pip install matplotlib
python src/plots.py

## Список запросов

1. **1.1** — администраторы ателье A, выполнившие заказ клиента B с фурнитурой C и тканью D
2. **1.2** — то же, но не менее двух совпадений (`HAVING COUNT(*) >= 2`)
3. **2** — число изделий, пошитых портным B в ателье A
4. **3.1 / 3.2** — заказчик с максимальным / минимальным количеством фурнитуры
5. **4** — распределение заказчиков по числу изделий (гистограмма)
6. **5** — число заказов и изделий на заказчика (двумерная гистограмма)
7. **6** — типы фурнитуры, использованные чаще фурнитуры A
8. **7** — заказчики, ни разу не использовавшие ткань A (антисоединение через `LEFT JOIN`)
9. **8** — число заказов по ателье и администраторам (3D-гистограмма)
10. **9** — `UPDATE`: замена фурнитуры A на B у изделия
